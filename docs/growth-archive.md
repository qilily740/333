# 成长档案（第二阶段）

## 入口与操作

主页 Experiences → 第二个横向类目「成长档案」。顶部头像沿用经历页面的角色切换器，五个类目固定。首页采用单张照片的相机取景器，下方横向调焦刻度支持触摸拖动、鼠标、方向键及左右按钮逐帧切换年龄阶段，松手吸附到最近一格。相册设置支持手动顺序及关闭轻柔动效，系统减少动态效果优先。

首次打开自动展示童年、少年、青年、成年四个空白阶段，使用无具体年龄、性别特征的简约线条头像。初次浏览不写入存储；用户保存档案或相册设置时才保存这些模板，`isTemplate` 标识空白阶段。用户编辑并保存后解除模板标记。默认阶段有稳定 ID，首次保存不会重复新增；删除的阶段也不会自动补回。有空白模板时沿用阶段顺序，填写完成后按已知年龄排序，未知年龄放在后面。

点击当前照片进入该阶段详情，保存或取消返回相册并保留当前焦距。详情可修改名称、年龄、性格表现、兴趣、人际相处、说话方式、外貌、穿着及影响阶段的经历；可删除阶段、调整手动顺序。照片从本机选择，经画布缩放至最长边 1200 px 后保存为 JPEG；可更换或移除，移除后恢复默认头像，无自动生成照片。

阶段详情统一黑白灰配色，采用左侧白色细边照片、右侧阶段名称及年龄范围的布局；无米黄底色与装饰阴影。稳定性格底色直接在本页编辑，与阶段资料通过同一次保存操作写入，数据仍分字段存储，不修改原角色人设。多行输入框沿用线上设置「补充经历」的横线纸张样式。删除、保存、上一阶段、下一阶段、新建阶段、API 填写固定在五个主类目下方，详情内容独立滚动；上一阶段／下一阶段用于切换档案，离开未保存表单会提示。经历关联只允许选择当前角色人生时间线中已确认的经历；关联保存稳定经历 ID，不复制或改写经历。已失效的历史引用保存时不会被默默删除。

## 数据结构与持久化

每个角色有独立 `character.growthArchive`：

- `schemaVersion: 1`、`ownerId: character.experienceCharacterId`
- `stableTraits`（稳定底色，与阶段表现分开）
- `sortMode: age | manual`、`motion`、`updatedAt`
- `stages`：阶段数组

每条阶段含 `id`、`name`、可为空的 `startAge/endAge`、`personality`、`interests`、`relationships`、`speech`、`appearance`、`clothing`、`influences`、`photo`（内嵌图片 data URL）、`timelineIds`、`source`、`provenance`（原始来源名、字段与摘录）、`status: confirmed`、`order`、`createdAt/updatedAt`。

采用现有 `IrisStorage.save`，保存到 Iris 的 IndexedDB，沿用 localStorage 降级机制。写入前检查当前角色对象及稳定 owner ID；异步照片读取、API 返回也检查归属与页面状态。存储失败恢复原始数据并在页面给出反馈，未保存表单保留。

## AI 建议

阶段详情固定栏的「API 填写」只展开位于操作栏下方的来源及审核面板。用户选择人设、当前启用的世界书和已确认人生经历后，点击来源行右侧「整理」才调用当前模型；每次点击都会发起新请求并替换上一份未采用的建议。首轮外貌少于180个非空白非标点字符，或穿着少于140个时，最多自动追加一次定向补写请求，要求外貌约220—320字、穿着约200—300字。只接受比原文更长的对应栏目，其他栏目保持首轮结果；补写失败保留首轮建议并提示，返回仍偏短也显示提示，不循环调用。补写同样支持站内离开后继续。复用设置中「经历」API，不新增配置。

提示词采用成长档案设计结构：`coreIdentity` 提炼稳定底色、价值观、边界和 OOC 风险；`stages` 分别描述阶段性格、外貌、穿着、说话、兴趣、相处、变化与不变特质；`consistencyReview` 列出矛盾、无依据假设和待确认问题。每个栏目另附可核对的 `sources` 原文摘录。资料足够时要求性格、外貌、说话与相处等主要栏目约180—300字，兴趣和穿着约120—220字，可分自然段，允许有依据的细致推演，区分明确设定、合理推演和待确认；不补造重大经历、具体身体参数或确定因果。

解析器将结构化结果映射到现有表单字段，正文不插入【明确设定】等审核前缀，审核标记留在建议区域。推演理由、把握程度、矛盾与问题显示在审核区，资料不足返回的补充问题也会显示。兼容早期扁平阶段 JSON。勾选「人设」时同时提供当前角色已经保存的稳定底色及已确认阶段作为一致性参考，未保存输入不当作已确认设定。只整理当前选定阶段，模型返回的 ID 不用于替换本地阶段身份。

建议仅在当前页面供审核，不自动持久化，也不写入人设、世界书或聊天记忆。七个描述栏目要求逐一提供具体建议；有真实来源时展示原文，缺少直接摘录的描述保留为待确认方向，不再静默清空。审核区说明依据缺口，采用时保存待确认推演的来源元数据，不伪造引文。具体年龄和事实经历仍须有可核对的依据，缺失时留空。已有内容默认不勾选覆盖。采用后填入表单，用户点击「保存」才持久化；照片保持原样。请求和结果按角色稳定 ID 与阶段 ID 保存在当前页面会话的任务表；站内离开、切换角色或阶段后继续运行，返回对应阶段可查看进度及结果。不会自动保存正式档案。刷新或关闭网页后任务不保留。展示和采用时再次校验角色、所选资料及目标范围，发生变化时拒绝应用旧结果。采用已核对来源的建议字段时，自动勾选对应的已确认人生经历，保留手动关联并允许调整。

## 备份

接入现有 JSON/ZIP 全量导出、导入、自动备份及恢复链路；内嵌照片随数据一起保存，无临时 blob URL。自定义备份增加「成长档案」分类，预览显示成长阶段数量。仅选成长档案时保留角色身份用于安全对齐，不导出人设和聊天内容。

合并按角色稳定 ID 对齐、阶段 ID 去重，同 ID 使用更新时间较新的完整阶段，保留有意清空的字段；空白模板优先级低于用户保存过的阶段，不会覆盖已有内容。档案级底色及设置采用更新时间较新的版本。分类替换仅影响备份明确包含的角色成长档案，旧备份没有此字段时保留本地档案，不清空其他角色。备份结构检查拒绝重复阶段 ID、角色归属不一致及无效年龄。备份格式版本仍为 4，兼容旧版本 2/3/4 备份。

## 尚未包含

地球地图、人物与成就（奖项、NPC 评价）、IF 世界仍未实现。成长档案不自动影响聊天上下文或长期记忆，不自动生成阶段照片。

实现仅在本地，未推送、部署或更改应用版本号。调焦交互、默认阶段保存、单阶段建议的审核保存、角色隔离、失败回滚、照片移除及模板备份合并有 DOM／数据测试覆盖；未进行手机浏览器视觉检查。
