# Iris 地球地图

实现位于 `scripts/earth-core.js`（数据、校验、球面几何）与 `scripts/earth.js`（独立经历面板）。使用原生 Canvas 将 Natural Earth 陆地轮廓制成的奶白纸质地图投影到真实球面，没有新增运行时依赖；旋转时重绘纹理，动画独立绘制城市、大圆航段与进度。拖动、滚轮、双指缩放、键盘、复位；播放、暂停、重播、速度、拖动时间轴；城市/航段选择与列表同步。虚线代表未确认路线，实线代表用户确认，原始资料状态仍保留。

生成统一使用单独分配的 `experiences` API 路由与模型，复用现有 JSON 模式请求；未分配经历接口时提示配置，不回退到聊天接口。输入包括当前角色资料、当前线上读取范围允许的角色和全局世界书、已确认人生时间线及已有路线。严格解析 JSON，忽略模型坐标；所有生成航段统一标为合理推演，不生成待确认问题；原文是否匹配单独记录，不把推测冒充事实。原文匹配只表示找到摘录，不能证明其语义支持整段路线，仍必须人工审核。

生成任务离开分类或经历页面后继续，在原角色仍存在且资料未改变时保存到原角色；返回页面可查看进行中状态与结果。后台任务在网页会话内运行，不承诺关闭或刷新网页后继续。全部模型结果先保存为 pending，重新生成前明确提示保留已有草稿并追加。确认后 review=confirmed；编辑后重新变成 pending；忽略不播放；删除明确提示。没有修改人设、世界书、聊天或长期记忆。数据存于各角色 `earthTravel`，检查 ownerId；写入使用现有持久化并在失败时回滚。确认路线只在地球旅行经历内正式展示，不复制到人生时间线，以免产生重复或隐式写入。

新增备份分类 earthTravel：包含草稿、确认/忽略状态、原始来源和用户选择的 GeoNames 城市 ID。支持完整/分类 JSON 与 ZIP 导出、按角色稳定身份恢复、新版本航段合并及分类替换；旧备份没有地图字段时保留当前地图。城市坐标来自本地数据集，未收录的小城市、虚构或历史地点保留待定位，用户可改名并选取数据集中的城市，无法验证的坐标不绘制。

静态资源沿用现有发布查询参数；默认索引、样式、启动脚本缓存标识更新至 r30。地球资源随当前 iris-release 参数加载，没有增加 service worker 或更改部署配置。未部署。资源和许可见 `assets/EARTH-SOURCES.md`。不需要地图服务或额外密钥，只有点击生成才调用已分配的经历 API。

## 奶白纸质与身份推演

根据用户选择，默认地球改为暖白海洋、灰绿陆地和克制的球面阴影，不再加载卫星纹理。采用公共领域 Natural Earth 1:110m 陆地数据生成本地 SVG，构建脚本使用 Python 标准库，运行时无新增依赖。已通过离线球面静态预览检查配色及地理朝向，未声称完成真实浏览器视觉验收。

生成提示明确将原设定城市视为生活锚点，而非目的地白名单。根据实际提供的职业阶段、经济条件、年代、兴趣、家庭、居住地和活动范围，推演资料未提及的城市；不得自行补出财富、职业、人脉或具体活动作为事实。每段新增 basis，描述身份到目的地的推理链条与未知部分；source/quote 引用支持推理前提的真实资料，不要求包含新目的地，不作为确实到访证据。所有新路线仍是合理推演，先待用户选择采用，不生成问题清单。

## 黑白灰与放大范围

按最新要求，地球底图改为灰白海洋和中灰陆地，城市文字与飞机改用灰黑；红色实线和青色虚线继续区分航线状态。默认球体半径由 205 增至 225 像素，放大上限由 2 倍提高到 4 倍，按钮、滚轮和双指缩放采用同一上限，复位回到更大的默认视图。缓存标识更新至 r31。

播放、重播、切换航段、拖动时间轴及选择航段均保持当前地球朝向与缩放，不再自动定位航段起点。只有手动旋转、缩放和复位改变视角。缓存标识更新至 r32。

## 丰富路线与自动采用

按最新要求，旅行生成规模上限从40提高至120段，富有且有出行意愿、自由时间或国际活动依据的成年角色可推演更多国家与城市；提示给出15—35座不同城市、30—80段的条件式规模参考，不是强制配额，性格、年龄、预算与世界设定仍约束频率。原文未提及的目的地允许推演。完整实际模板见 `docs/experiences/earth-route-prompt.md`。

新生成路线直接 review=confirmed，confirmation=api-generated，不要求逐条用户核定；仍统一标合理推演，保存不等于原作事实。编辑后直接保存，隐藏后恢复也直接显示。已有草稿不批量改写。列表改为细分隔线、轻字号与文字操作，去掉圆角卡片、厚边框和彩色侧栏，完整背景与推测依据点击查看。缓存标识r33。

## S 形城市时间路线

旅行列表改为三节点一行的响应式 SVG，按时间从左向右，再右侧向下、从右向左、左侧向下循环。连续航段共享城市节点；不连续的行程之间保留断点，不添加虚构连接。每个城市显示对应年龄或年份，未知显示时间未记。可点击或用 Enter/空格选择两城间的线，打开原生 dialog 路线卡片，查看两端城市、旅行原因、停留时间、推理依据和折叠的设定原文；关闭按钮、Esc 和遮罩可退出。编辑、隐藏及删除操作收在弹窗中，隐藏路线可从折叠区恢复。播放只更新独立状态区域，不会替换弹窗或移动地球。

生成结构新增 stay，用于目的城市推测停留时长；旧数据或未知时显示未记录，支持手动编辑与原备份机制保存。生成按钮统一黑色文字和黑色底线。相关26项测试通过，包括时间排序、左右交替折返、键盘打开弹窗、停留时长和未知回退。浏览器视觉与手机真机触控尚未实测。缓存标识r34。

## 每段日期、停留与原因

新生成路线强制要求具体出发日期date、整数停留天数stayDays、非空出行原因purpose，缺失或非法日期时整次结果不保存，已有内容保留。公历日期使用YYYY-MM-DD，没有公历年代锚点时用N岁-MM-DD年龄历表示，不虚构出生年。月日和停留天数作为推测行程，弹窗明确标为推测。日期与已有年龄/年份字段冲突也拒绝保存。S形节点优先显示日期，同年龄/年份内按可比较的日期排序，编辑表单支持并校验这三项。旧数据不自动编造日期，可通过编辑补齐或重新生成。相关27项测试通过；缓存标识r37。

最新界面修订：S形城市与日期使用经历面板继承字体、常规400字重，与小类目相同；S形连线在默认、播放和悬停状态均为灰色虚线，地球上的航线仍为红色。删除地球下方已保存航线图例，收紧播放器及路线间距，默认速度2倍（实际播放变量与选择器均同步）。缓存标识r38。

地球子导航与经历分类之间显式取消顶部margin、padding与父级row-gap，并将子导航横向分隔线铺满分类宽度，消除面板内边距形成的两侧断口；手机使用相应12px内边距补偿。缓存标识r39。

字体粗重根因：全局 svg 图标样式的 stroke:currentColor / stroke-width:1.5 被SVG文字继承，造成字形轮廓膨胀。已在地球S形SVG及城市/日期text显式取消stroke，保留连线的独立灰色虚线描边。常规400字重与经历分类一致；未修改全局图标规则。缓存标识r40。

## Persisted candidate geocoding (r63)

Generation now resolves both new and old routes against the local GeoNames catalog. Unique matches are saved directly; ambiguous endpoints are sent in batches of 30 to the configured Experiences API, with an explicit whitelist of real candidate IDs. Responses cannot supply coordinates or modify journey fields. Endpoints store query, ID, latitude, longitude, country, admin1, displayName, matchMethod, matchBasis and resolvedAt. Existing manual selections are preserved. The separate city-location completion button upgrades old routes without generating travel. Background completion still saves only to its original role, including after navigation. Failed location calls preserve generated journeys and report remaining unresolved points. Playback and review do not call APIs. Backup restore retains the selections and matching rationale. No additional map-service key is needed. Default playback is 4x.
