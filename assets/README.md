# 素材与数据索引

| 文件或目录 | 用途 |
| --- | --- |
| [fonts/](fonts) | 字体文件、字体样式及各字体许可证；来源见 [fonts/SOURCES.md](fonts/SOURCES.md) |
| [gpt-icons/](gpt-icons)、[notes-icons/](notes-icons)、[x-icons/](x-icons) | 心声及相关面板使用的图标 |
| `iris-app-icon-*` | 安装到主屏幕时使用的应用图标 |
| [chat-gift-box.webp](chat-gift-box.webp) | 聊天礼物盒图片 |
| [earth-cities.json](earth-cities.json) | 地球地图与旅行定位使用的本地城市资料 |
| [earth-paper.svg](earth-paper.svg)、[earth-blue-marble.jpg](earth-blue-marble.jpg) | 地球绘制使用的地图素材 |
| `earth-boarding-pass.*` | 旅行登机牌与票面素材 |
| `growth-camera-*` | 成长相册的相机界面素材 |
| `if-*` | IF 开场与分支页面的装饰素材 |
| `award-*` | 正式及趣味奖项的纸张素材 |
| [timezone-regions.json](timezone-regions.json) | 时区地区资料；说明见 [timezone-regions.README.txt](timezone-regions.README.txt) |
| [vendor/](vendor) | 第三方资源和许可证 |

地图与城市数据的来源、许可和维护命令见 [EARTH-SOURCES.md](EARTH-SOURCES.md)。生成素材的工具集中在 [tools/earth](../tools/earth/README.md)。同名 PNG、WebP 或不同尺寸文件用于不同显示场景，引用关系由代码和样式决定。
