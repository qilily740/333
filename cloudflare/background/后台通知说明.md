# Iris 后台主动联系

本服务独立于音乐 Worker，使用 SQLite Durable Objects 保存每个安装实例的状态和闹钟。前端只在用户主动开启系统通知后上传当前聊天角色的必要设定、最近聊天、可邀请作品名称及 API 配置。配置和待收消息使用 AES-GCM 加密；浏览器设备令牌只保存哈希，推送使用标准 aes128gcm 和 VAPID。

## 用户操作

在当前角色的 More → 角色互动中开启主动联系，设置频率，再点击「开启系统通知」。iPhone/iPad 需要先添加到主屏幕，从主屏幕打开后授权通知。后台服务只跟随最后正在聊天的角色与绑定用户；前台运行时维持短租约，后台不会重复生成。

默认后台免打扰时间为用户时区的 23:00–08:00，可修改或关闭。每设备每天最多判断 24 次，一条主动消息生成后等待用户回应；服务器每日总判断上限默认 1000。关闭后台通知会删除云端设定、API 配置、订阅与待同步消息；连接 30 天不更新会自动清理。服务端保留的设备令牌哈希不含聊天资料。

生成的消息先持久保存，再发送系统推送。通知失败重试同一条已保存消息，最多三次，不重复调用模型。通知订阅失效时提示重新开启。重开页面先同步待收消息，持久写入本机后再确认收取；消息按稳定角色和用户 ID 放回原会话。已删除、拉黑或改绑的身份不会收到旧任务的消息。后台仅生成文字和现有作品邀请，不执行钱包或项目操作。

## 部署

配置文件是 `wrangler.jsonc`，部署为独立的 `iris-background` Worker，域名 `background-api.suri.us.ci`。当前 Worker 使用的 API 为用户原有 OpenAI 兼容聊天接口，必须是公网 HTTPS 域名，本机地址不支持。

部署前设置三个独立于音乐服务的密钥：

- `BACKGROUND_ENCRYPTION_KEY`：32 字节随机 AES 密钥，base64url。
- `VAPID_PRIVATE_JWK`：P-256 ECDSA 私钥的 JWK JSON。
- `VAPID_PUBLIC_KEY`：对应 65 字节未压缩公钥，base64url。

`VAPID_SUBJECT` 是服务联系网址。密钥仅通过 Wrangler secrets 上传，不写进前端或版本库。不要随意更换 AES 密钥，否则旧云端数据将无法解密；更换 VAPID 密钥需要设备重新订阅。新设备注册及模型调用都有服务端每日限额，不能由浏览器请求取消。

接口 `/health` 只公开版本、就绪状态和 VAPID 公钥。设备接口 `/v1/devices/<uuid>/{config,state,messages,ack}` 必须同时满足来源白名单和设备 Bearer 凭据。更换自己的域名时同步修改 `ALLOWED_ORIGINS`，前端「连接与隐私」中可填写自己的后台服务地址。

## 检查

- `node --test cloudflare/background/background.test.cjs`：身份校验、加密、时间、去重、预算、静默决定和推送协议。
- `wrangler deploy --config cloudflare/background/wrangler.jsonc --dry-run --outdir /private/tmp/iris-background-bundle`
- `node --test cloudflare/background/runtime.test.cjs`：实际本地 workerd 与 SQLite 闹钟执行，使用模拟聊天和推送服务，不发送真实通知。
- `node --test tests/background-contact.test.cjs tests/proactive-events.test.cjs`：页面订阅、前后台切换、原会话同步、失败回滚及通知点击。

真实手机仍需由用户授权通知。网络和操作系统可能延迟送达，不能保证系统通知精确到秒。
